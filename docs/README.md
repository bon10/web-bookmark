# docs

このアプリの「決めごと」を置く場所。コードを読めば分かること（構造・手順）ではなく、**なぜそう決めたか**と**どの言葉を使うか**を書く。

| ドキュメント | 中身 | いつ読むか |
| --- | --- | --- |
| [ユビキタス言語](ubiquitous-language.md) | ドメイン用語の定義、UI ラベル一覧、DB との用語の不一致 | 変数名・関数名・UI 文言を決めるとき |
| [デザイン方針](design-system.md) | 意匠の芯、色トークン、テーマ切り替え、書体、共通クラス | 画面や部品を足す・直すとき |
| [ADR](decisions/README.md) | 設計上の判断と、それを将来見直すための条件 | 構成・経路・責務の分け方を決めるとき／決めた後 |

## 運用

- **辞書がソース。** 実装と食い違ったら、まず辞書を直してから実装を直す
- **概念を足すときは同じ作業の中で辞書に書く。** 「あとで書く」はしない
- 方針から外れる必要が出たら、外れる前にこのドキュメントを更新する
